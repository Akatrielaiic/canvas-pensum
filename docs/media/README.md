# Media for the README

Short GIFs, 5–10 seconds each, one gesture per GIF. Record them at about 900 px wide, all in the
same theme, with the pressed keys visible (KeyCastr or similar). Save them here with these names;
each one has a commented-out line waiting for it in the main README.

| File | Shows |
|---|---|
| `task-to-card.gif` | Writing `- [ ]` in a note; its card appears in the Inbox. The hero image. |
| `done.gif` | Ticking the last task on a card: it turns green and moves to Done. |
| `add-task.gif` | Cmd/Ctrl+Shift+A on the Pensatorium: pick a note, the cursor lands in its card. |
| `move-to-zone.gif` | Selecting two cards, Cmd/Ctrl+Shift+M, typing a new zone name, Enter. |
| `responsive-zone.gif` | Dragging a card into a zone and out again: the zone grows and shrinks. |
